# SINKHAWM — Learning Together

## Free English–Zomi (Tedim) Language Resources

This repository provides free educational dictionaries and language-learning datasets.

### Available Datasets
1. Essential 3000 English–Zomi Learner's Dictionary
2. English–Zomi 100,000 Sentences
3. 50K English–Zomi–Burmese Dictionary

### BETA Release — Native Speaker Review Needed

**All three datasets are currently BETA versions.**

These resources are works in progress. Some translations, definitions, spelling, grammar, word meanings, and example sentences may contain errors or need improvement.

Not all entries have been independently verified by native Standard Zomi (Tedim) speakers.

We welcome corrections, suggestions, and feedback from native speakers and language experts.

**Review status:** BETA — Native speaker verification ongoing or pending.

### About

SINKHAWM — Learning Together is an educational initiative supporting Standard Zomi (Tedim) language learning, preservation, and development of digital and AI language resources.
